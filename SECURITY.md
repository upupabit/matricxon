# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- **Email:** support@bytepenny.com, with "Security" in the subject.
- **GitHub:** use "Report a vulnerability" on this repository's Security tab.

Please include the affected version, steps to reproduce, and the impact you expect.

## What to expect

- We confirm receipt within 3 business days.
- We send a first assessment within 10 business days.
- We fix confirmed issues in the latest release and publish an advisory once a fix is out.
- We coordinate the disclosure date with you, normally within 90 days of the report, and credit you if you wish.

## Supported versions

Security fixes go into the latest release of Matricxon. Please update before reporting.

## Scope

Matricxon's own code, its install scripts and its default configuration. Issues in third-party models, engines or
libraries should go to their maintainers, but tell us too if Matricxon is affected.
